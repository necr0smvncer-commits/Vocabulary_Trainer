# Vocabulary Trainer
A simple vocabulary learning application developed in C# using Windows Forms. The application loads vocabulary lists from JSON files and allows users to practice translations.

## **Features**
- Load vocabulary lists from JSON files.
- Select random vocabulary entries.
- Check user answers.
- Remove correctly answered words from the vocabulary.
- Infinity Mode: practice without removing words from the vocabulary.

## **Install**
1. Follow these steps to download and run the application:
2. Open the [Releases](https://github.com/users/necr0smvncer-commits/releases) page.
3. Download the latest .zip file under Assets.
4. Extract the downloaded archive to a folder of your choice.
5. Open the extracted folder.
6. Double-click VocabularyTrainer.exe to launch the application.
