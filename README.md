# Vocabulary Trainer
A simple vocabulary learning application developed in C# using Windows Forms. The application loads vocabulary lists from JSON files and allows users to practice translations.

## **Features**
- Load vocabulary lists from JSON files.
- Select random vocabulary entries.
- Check user answers.
- Remove correctly answered words from the vocabulary.
- Infinity Mode: practice without removing words from the vocabulary.

## **Install**
### Follow these steps to download and run the application:
1. Open the [Releases](https://github.com/necr0smvncer-commits/Vocabulary_Trainer/releases/tag/v1.0.0) page.
2. Extract the downloaded application to a folder of your choice.
3. Double-click VocabularyTrainer.exe to launch the application.
